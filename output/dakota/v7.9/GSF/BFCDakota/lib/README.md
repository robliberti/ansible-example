# Dakota Version 7.9 Libraries

This directory contains the following libraries for Dakota 7.9:

* dakotalib-core-7.9.jar
* dakotalib-extras-7.9.jar
* legacy-xml-parser.jar
* commons-logging-1.1.jar

When creating a complete package, these library placeholders should be replaced
with the actual JAR files from the corresponding Dakota 7.9 release.
